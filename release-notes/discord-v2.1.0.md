# AIM: Actor Window 2.1.0 — готовится к выпуску

В этом обновлении — более надёжный перенос предметов и обновление окна без лишних задержек.

### Перенос предметов
- Исходный предмет удаляется только после подтверждения получения. Посторонние изменения в инвентаре больше не
  могут ошибочно подтвердить перенос.
- Для сумок проверяется получение содержимого целиком. При неполном переносе исходные предметы сохраняются,
  а изменения у получателя отменяются, если это безопасно. Если нужна ручная проверка, окно сообщает об этом.

### Экипировка и обмен
- Окно и стандартный лист dnd5e используют одинаковые правила надевания предметов.
- В режиме предупреждений старый предмет корректно освобождает занятый слот; надетая вещь выходит из сумки.
- Исправлена лишняя блокировка обмена у несвязанных токенов.
- Расчёт веса после обмена учитывает правила сумок Weighty Containers 3.10 и новее.

### Обновление окна
- Анимация HP больше не задерживает обновление инвентаря и торговой панели.
- Изменения не теряются, если окно уже перерисовывается.
- При редактировании биографии остальные части окна продолжают обновляться, а биография обновляется после завершения ввода.
- Закрытое окно больше не выполняет отложенные обновления.

### Совместимость
Foundry VTT 14 (проверено на 14.367) и dnd5e 5.3.3 (проверено на этой версии).
